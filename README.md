# Java Mastery

A structured, hands-on Java, DSA, and backend learning repository. Use the numbered modules as a path; each module has a checklist and space to collect notes, examples, and practice links.

## How to use this repository

1. Start with [the syllabus](src/syllabus.md) and follow modules in order.
2. In each module, mark concepts as you learn them and add concise notes/examples in that module folder.
3. Keep runnable Java solutions in the existing `src/` tree, grouped by topic and pattern. Use descriptive class names and one public class per file.
4. For each problem, record the prompt/source, approach, complexity, edge cases, and revisit date using the [problem template](docs/templates/PROBLEM.md).
5. Commit small milestones with clear messages, for example `study: add sliding window notes and solutions`.
